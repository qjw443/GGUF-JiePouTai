# GGUF 解剖台 · Windows 桌面版

纯 Python + Tkinter 的独立桌面程序：**不开浏览器、不起服务器、不依赖 WebView**，双击 exe 直接读 `.gguf`。

## 启动

```powershell
.\GGUF解剖台.exe                                  # 双击即可，自动加载同目录最大的原始模型
.\GGUF解剖台.exe --view ablate                    # 直接打开指定页面
python desktop\app.py ..\qwen2.5-0.5b-instruct-q4_k_m.gguf   # 从源码跑
```

`--shot out.png --shot-delay 9000` 是自检模式：启动 → 等待加载 → PrintWindow 抓窗口 → 退出。

## 拒答移除怎么做的

1. **构造方向**：从词元嵌入里取拒答语义词（`sorry` / `apolog` / `cannot` / `抱歉` / `无法` / `拒绝` …）的平均向量，
   减去中性语义词（`Yes` / `sure` / `okay` / `当然` / `可以` / `好的` …）的平均向量，单位化得到 `r ∈ ℝ^896`。
2. **定位载体**：所有写回残差流的线性层（`attn_output`、`ffn_down`）输出维都是 hidden=896，
   `r` 在其中占比 = `‖rᵀW‖ / ‖W‖`，本模型平均 **0.03351**，最高 `blk.19.attn_output` 的 **0.03838**。
3. **正交化**：`W ← W − r(rᵀW)`，词元嵌入按行做 `E ← E − (E r) rᵀ`，直接把该子空间删掉。
4. **导出**：被改的 49 个张量重新编码成 Q8_0，其余 242 个张量原样复制量化块，新文件 **588 MiB**。

实测（Qwen2.5-0.5B-Instruct q4_k_m）：

```
平均拒答能量  0.03351  →  0.00022      下降 99.3%
最高单矩阵    0.03838  →  0.00027
导出文件      588,490,592 字节，49 个张量被正交化
```

导出文件能被本程序与 llama.cpp 直接加载（截图里的 561 MiB 就是它）。

## 路径显示

顶部常驻一条路径栏：**完整模型路径 + 输出目录**，右侧三个按钮「复制路径 / 打开目录 / 最近打开 ▾」。
`最近打开` 记录本次会话加载过的 8 个文件，点一下直接切。路径过长时中间省略，复制到的仍是完整路径。

## 打包

```powershell
python -m PyInstaller --noconfirm --onefile --windowed --name "GGUF解剖台" ^
    --paths desktop --hidden-import numpy --hidden-import abliterate ^
    --exclude-module matplotlib --exclude-module scipy --exclude-module pandas desktop\app.py
```

产物 30.3 MB，单文件免安装，冷启动 6~10 秒，之后 3~5 秒。
